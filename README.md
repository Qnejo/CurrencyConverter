# Currency Converter (Конвертер валют)

Простое WPF-приложение для конвертации валют с использованием актуальных курсов Центрального Банка России.

## Технологии

- **.NET** – WPF (.NET Core / .NET 5+)
- **C#** – язык программирования
- **XAML** – разметка интерфейса
- **HTTP Client** – для запросов к API
- **System.Text.Json** – для парсинга JSON-ответов
